# Замер скорости интернета

Консольный скрипт: последовательно делает 10 запросов к адресу тяжёлого файла, дожидается полного скачивания каждого ответа и печатает среднее время запроса, объём скачанных данных и скорость в МБ/с.

Нужен только Python 3.8+, сторонних библиотек нет.

## Запуск

```bash
git clone https://github.com/korniychukg-sudo/internet-speed-meter.git
cd internet-speed-meter
python3 speedmeter.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Без аргументов скрипт берёт этот же адрес: фото с Wikimedia, около 15 МБ.

Параметры:

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `url` | адрес файла, который скачиваем | фото с Wikimedia |
| `-n`, `--count` | сколько запросов сделать | 10 |
| `-t`, `--timeout` | таймаут одного запроса, секунды | 30 |

## Пример вывода

```
Адрес: https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
Запросов: 3, таймаут: 30 с
  запрос  1:   8.06 с,  14.68 МБ,   1.82 МБ/с
  запрос  2:   8.33 с,  14.68 МБ,   1.76 МБ/с
  запрос  3:   7.49 с,  14.68 МБ,   1.96 МБ/с

Успешных запросов: 3 из 3
Среднее время запроса: 7.96 с
Скачано всего: 44.04 МБ
Скорость: 1.84 МБ/с (14.8 Мбит/с)
```

## Как считается

- Запросы идут строго по очереди: следующий начинается после того, как предыдущий полностью скачан.
- Время запроса считается от отправки до получения последнего байта тела ответа (`time.perf_counter`).
- Тело читается потоком по 64 КБ, поэтому большой файл не держится в памяти целиком.
- Скорость — это все скачанные байты, делённые на суммарное время успешных запросов. 1 МБ = 1 000 000 байт, в скобках та же скорость в Мбит/с.
- Ошибочные запросы (HTTP-ошибка, таймаут, обрыв сети) показываются в выводе, но в расчёт не идут. Если не удался ни один запрос, скрипт завершается с кодом 1.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты поднимают локальный HTTP-сервер и проверяют, что скачивается полное тело ответа, запросы идут последовательно, ошибки не портят расчёт, а средние и скорость считаются правильно.
